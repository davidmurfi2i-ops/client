# Paper Client (Fabric, Minecraft 1.21.4)
Jar bauen ohne PC-Setup: Ordner in ein neues GitHub-Repo hochladen -> Tab "Actions" -> "Build Paper Client" -> Artifact "paper-client-jar" herunterladen.
Lokal: gradle build -> build/libs/paper-client-1.0.0.jar (NICHT die -sources.jar).
Die .jar in den mods-Ordner (mit Fabric Loader + Fabric API). Rechts-Shift = Menü, V = Fullbright.
